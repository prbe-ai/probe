description: The Summary draft format and the rules for keeping a person's blocks.
---

Write the short bullets specified by `write-summary`. An HTML draft can be one `<ul>` with one `<li>` per bullet. A Markdown draft uses one `- ` line per bullet.

Leave each `<!-- kept: hN -->` block in its place and in order. The server puts the person's words back. Save detailed findings in Notes and consult Metrics for logged curves.

The dashboard supplies the project or experiment name. Start directly with the bullets.
